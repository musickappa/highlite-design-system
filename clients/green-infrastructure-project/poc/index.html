Imbanuma Green Infrastructure Project

「自然をうまく利用する」地域づくりへ。

千葉県印旛沼流域から始まる、気候変動適応と生物多様性保全を両立するグリーンインフラの実践。

私たちは、「社会課題の解決に生物や生態系の機能を損なわずに活用する」という転換を目指しています。谷津の再生活動や公共施設への雨庭の導入、IoTセンサーを用いた水管理など、産官学民の知恵を合わせて、自然と人間が豊かに共存できる流域の未来を築きます。

About

印旛沼流域を、自然の力で次世代へ。

千葉県印旛沼流域をモデル地域とし、気候変動への適応、水質浄化、および生物多様性の保全（ネイチャーポジティブ）を同時に目指すグリーンインフラの実践プロジェクトです。

国立環境研究所（気候変動適応センター・内閣府SIP事業）が持つ最先端の科学的知見と、1984年の設立以来、流域13市町と一体で水質保全を支えてきた印旛沼環境基金の地域ネットワークを掛け合わせ、確かなエビデンスに基づいた社会実装を行っています。

「社会課題の解決に生物や生態系の機能を損なわずに活用する」という転換を目指し、産官学民が一体となって活動を展開しています。

Activities

産官学民が一体となった、
3つの実践軸

グリーンインフラの普及・実装に向け、「場づくり」「フィールド実践」「知の連携」の3軸で活動を展開しています。

03
01 / 03
🌿

産官学民がフラットに集まる「里山グリーンインフラ勉強会」

事務局と約120名の個人が参加する、メンバー非固定の開かれた連携の場をほぼ毎月開催。市民、研究者、行政、企業が立場の壁を越えて「自然を活かした豊かな地域づくり」を本音で議論・情報共有しています。

02 / 03
🏞️

地域の課題を資源に変える「多角的なフィールド実践」

絶滅危惧種（ニッポンフラスコモ等）が育つ水源樹林の手入れや、畦・水路の補修による谷底面の湿地化をはじめ、公共施設での雨庭設置、農業者と連携した耕作放棄地の新たな活用など、現場に根ざした実装を進めています。

03 / 03
🔬

国立環境研究所×印旛沼環境基金による「強固な推進体制」

国立環境研究所（気候変動適応センターや内閣府SIP事業）が持つ最先端の科学的知見・予測データと、1984年の設立以来、流域13市町と一体となって水質保全を支えてきた印旛沼環境基金の地域ネットワークを掛け合わせ、確かなエビデンスに基づいた社会実装を行っています。
